## ⚡ About Me

Hey! I'm Abu Bakr Siddiq — a **Motion Designer, Video Editor, and Creative Builder**.

I focus on crafting visual stories, motion graphics, and clean UI/UX designs. When it comes to building on the web, I keep things practical: using basic web stacks, **vibe coding**, and leveraging AI tools and automations to bring ideas to life fast.

- 🎬 **Motion & Video:** After Effects, Premiere Pro, DaVinci Resolve
- 🎨 **Design:** Figma, UI/UX layouts, and visual design tools
- 💻 **Code:** Web basics (HTML, CSS, JavaScript) + Vibe Coding
- 🤖 **Workflows:** AI-assisted development, prompt engineering, and automations
- 🚀 **Currently Building:** [Motionly v2](https://github.com/abubakr-bd/motionly-v2) & [Motionly Media](https://github.com/abubakr-bd/motionly-media)
